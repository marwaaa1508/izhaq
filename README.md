# 💍 Izhaq Weds Naeema - Wedding Invitation Website

This is a custom wedding invitation website built using:
- HTML
- CSS
- JavaScript
- YouTube API (for background music)

---

## ✨ Features
- Elegant landing page (Bismillah + couple name)
- "Save the Date" interactive button
- Smooth scroll animation
- Background wedding music (YouTube)
- RSVP via WhatsApp
- Fully mobile responsive
- GitHub Pages compatible

---

## 🎵 Music Setup
The background music uses:
https://www.youtube.com/watch?v=uaKyS6gqTxI

It plays only after user clicks "Save the Date" (browser requirement).
